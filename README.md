# 🏡 EduStay

### Developed by Velixion (Pty) Ltd

> Helping students find accommodation. Helping property owners fill vacancies.

EduStay is a modern student accommodation platform built specifically for South Africa. It connects students with verified accommodation while providing property owners with powerful tools to market and manage their properties.

Built with React, TypeScript, Vite and Supabase, EduStay is designed to become a complete student accommodation management ecosystem.

# ⚙️ Getting Started

Clone the repository

```bash
git clone https://github.com/zanevdm03/edustay-site.git
```

Install dependencies

```bash
npm install
```

Create a `.env` file

```env
VITE_SUPABASE_URL=YOUR_SUPABASE_URL
VITE_SUPABASE_PUBLISHABLE_KEY=YOUR_SUPABASE_PUBLISHABLE_KEY
```

Start the development server

```bash
npm run dev
```

Build for production

```bash
npm run build
```
